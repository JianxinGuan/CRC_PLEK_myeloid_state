# Protocols and locks

Frozen plans and audit records are retained as source-stage records. The manuscript describes these as version-controlled staged analysis locks, not external prospective preregistration.

This is a lightweight, auditable release. It retains final figures, compact figure data, selected decision records, and lock specifications. Large raw expression objects, H5AD/RDS files, GEO/TCGA downloads, and intermediate stage outputs are intentionally excluded. Full recomputation therefore requires retrieving the cited public source data and using the complete analysis workspace; this release supports audit of the reported analysis plan and final outputs rather than one-command regeneration of every intermediate result.
